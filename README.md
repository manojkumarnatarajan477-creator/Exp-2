# Exp - 2 LIBRARY MANAGEMENT SYSTEM

## AIM:
To design and develop a Library Management System using UML diagrams to represent the activities, interactions, structure, and communication between Member, Librarian, Book Keeper, and Admin.
## SRS (Procedure): Problem Identification
### Step 1: Problem Identification


The main problem is managing library activities such as book searching, borrowing, returning, reserving, and maintaining book records manually. The system aims to make library operations easier, faster, and more accurate.

### Step 2: Requirement Analysis

Identify the main users: Admin, Librarian, Member, and Book Keeper.

Define the main functions: Get membership, borrow books, return books, reserve books, maintain books, manage memberships, update availability, and generate reports.

### Step 3: System Design

Design the UML diagrams, including Use Case, Class, Activity, Sequence, Communication, and Package diagrams.

Identify the classes, attributes, methods, relationships, and interactions between different users and the library system.

### Step 4: Diagram Development and Verification

Create all six UML diagrams using StarUML. Check the relationships, activities, message flow, and system structure to ensure that all diagrams correctly represent the Library Management System.
